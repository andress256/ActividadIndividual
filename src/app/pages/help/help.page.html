Manual de usuario

Incidencias360 sirve para registrar, consultar y analizar las incidencias internas de la empresa (averías, problemas informáticos, peticiones…). Pulsa cada apartado para desplegarlo.

Acceso y roles

Entra desde la pantalla Iniciar sesión con tu usuario y contraseña. Hay dos perfiles:

  • Usuario estándar: consulta, crea y edita incidencias y descarga informes.
  • Administrador: además accede al Cuadro de mando con métricas y gráficos.

Si intentas abrir una página sin permiso, la aplicación te devuelve a una página permitida. La sesión caduca a la hora; usa Cerrar sesión en el menú al terminar.

Navegación

Abre el menú lateral con el botón ☰ de la barra superior. En pantallas pequeñas también puedes deslizar desde el borde izquierdo.

Gestionar incidencias
  1. En Incidencias verás la tabla con todas las incidencias.
  2. Escribe en el buscador para filtrar por título, código o departamento.
  3. Pulsa el nombre de una columna para ordenar; púlsalo otra vez para invertir el orden.
  4. Usa Anterior y Siguiente para cambiar de página.
  5. Pulsa el título de una incidencia para editarla y cambiar su estado.
  6. Con Nueva incidencia registras una nueva.

Al escribir el título, la aplicación comprueba en el servidor que no exista otra incidencia con el mismo nombre y te avisa antes de guardar.

Cuadro de mando (administrador)
  • Los filtros de búsqueda, estado, prioridad y fechas actualizan al momento las cifras, los gráficos y la tabla.
  • Pulsa una tarjeta de estado (Abierta, En curso, Cerrada) o un sector del gráfico para filtrar por ese valor.
  • El bloque Actividad en tiempo real muestra los últimos cambios sin recargar la página.

Informes PDF y CSV

Los botones Exportar PDF y Exportar CSV descargan las incidencias que se ven en ese momento (con la búsqueda o los filtros aplicados).

  • El PDF incluye la fecha, los filtros, un resumen por estado y la tabla paginada.
  • El CSV usa punto y coma y se abre directamente en Excel con las tildes correctas.

Accesibilidad y teclado
  • Pulsa Tab al cargar la página para ver el enlace Saltar al contenido principal.
  • Todos los controles se usan con Tab, Mayús+Tab, Enter y Espacio.
  • Puedes ampliar el texto con el zoom del navegador (Ctrl++) sin perder contenido.
  • La aplicación respeta el modo oscuro y la opción de reducir animaciones del sistema.

Datos y privacidad

Todos los datos son sintéticos: no hay información personal real.

  • Incidencias y departamentos: API REST relacional (SQL) simulada.
  • Actividad en tiempo real (NoSQL): {{ provider }}.
